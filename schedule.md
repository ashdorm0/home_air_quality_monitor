Day 1 — Planning and setup
Goal: Establish exactly what you are building.

Tasks:
1. Identify the single most important functionality your system needs.
2. Define what constitutes a successful first iteration.
3. Decide which technologies and libraries you need.
4. Create your project directory and Git repository.
5. Set up your development environment.
6. Create a basic README.
Deliverable: A functioning project environment with a clearly defined first-iteration scope.

Avoid spending too much time designing the entire system.
Day 2 — Implement the core functionality
Goal: Start building the actual system.

Tasks:
1. Implement the main processing logic.
2. Create the necessary modules and functions.
3. Establish communication between components, if required.
4. Test individual functions as you develop them.
Deliverable: An initial working version of your main feature.

Prioritise functionality over code optimisation.
Day 3 — Complete the prototype
Goal: Get your core functionality working from start to finish.

Tasks:
1. Finish any incomplete functionality.
2. Connect the necessary modules.
3. Add basic error handling.
4. Verify that the system produces the expected results.
5. Fix problems preventing successful execution.
Deliverable: An end-to-end working prototype.

By the end of Day 3, you should have something you can demonstrate.
Day 4 — Testing and refinement
Goal: Make sure your implementation is reliable.

Tasks:
1. Write basic automated tests.
2. Test successful and unsuccessful inputs.
3. Fix discovered bugs.
4. Improve code readability.
5. Remove unnecessary or unused code.
Deliverable: A tested prototype with evidence that its main functionality works.

You don't need an extensive testing framework, but you should be able to demonstrate that your implementation behaves correctly.
Day 5 — Documentation and finalisation
Goal: Prepare your iteration for assessment or demonstration.

Tasks:
1. Finalise your README.
2. Document your implemented functionality.
3. Record the tests you performed and their results.
4. Explain any limitations.
5. Identify what you intend to implement in Iteration 2.
6. Verify that your project runs successfully from a clean setup.
Deliverable: Your completed first iteration.
